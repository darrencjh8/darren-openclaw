## Fresh Install

### Prerequisites
- Docker and Docker Compose installed

### Steps

**1. Clone and configure core modules**
```bash
git clone <repo-url> ~/darren-openclaw
cd ~/darren-openclaw

# Portfolio Tracker
cp modules/portfolio-tracker/.env.example modules/portfolio-tracker/.env
# Edit: DEEPSEEK_API_KEY, ACTUAL_BUDGET_URL, ACTUAL_BUDGET_PASSWORD, ACTUAL_PRIMARY_BUDGET_FILE, ACTUAL_SECONDARY_BUDGET_FILE

# Expense Tracker
cp modules/expense-tracker/.env.example modules/expense-tracker/.env
# Edit: DEEPSEEK_API_KEY, ACTUAL_BUDGET_URL, ACTUAL_BUDGET_PASSWORD, ACTUAL_PRIMARY_BUDGET_FILE, ACTUAL_SECONDARY_BUDGET_FILE,
#       IMAP_HOST, IMAP_USERNAME, IMAP_PASSWORD, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID

# Gateway (OpenClaw + actual-api)
cp gateway/.env.example gateway/.env
# Edit: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, DEEPSEEK_API_KEY, OPENCLAW_GATEWAY_TOKEN,
#       ACTUAL_BUDGET_URL, ACTUAL_BUDGET_SERVER_URL, ACTUAL_BUDGET_PASSWORD,
#       ACTUAL_PRIMARY_BUDGET_FILE, ACTUAL_SECONDARY_BUDGET_FILE
```

**2. Deploy all services**
```bash
cd ~/darren-openclaw
./modules/deploy.sh
```

This validates all required env vars for each module, then runs `docker compose up -d` which picks up the override file automatically.

**3. Verify**
```bash
# Core services
curl http://localhost:3000/health   # actual-api
curl http://localhost:8080/health   # expense-tracker
curl http://localhost:8081/health   # portfolio-tracker
```

## How Module Registration Works

Pluggable modules add themselves via `docker-compose.override.yml`. Docker Compose automatically merges `docker-compose.yml` with `docker-compose.override.yml` on every `docker compose up`.

The override pattern:
- Services: adds the module's container to the same Docker network
- Skills: copied to `gateway/workspace/skills/<module-name>/SKILL.md` at deploy time
- OpenClaw discovers them from `/home/node/skills/<module-name>/SKILL.md` at startup

This is fully idempotent — writing the same override file and running `docker compose up -d` again produces no changes.

## Adding a New Pluggable Module

A pluggable module must:
1. Provide a Docker image exposing a REST API with `/health` + `/tools/*` endpoints
2. Provide `skills/SKILL.md` to be copied into the gateway's skills workspace
3. Write a `docker-compose.override.yml` with the service definition
4. The module's `deploy.sh` writes both the override file and copies the skill to the gateway directory for idempotent registration
