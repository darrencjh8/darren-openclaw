# Data Model: Expense Tracker Memory with Embeddings

**Feature**: 011-expense-memory-embeddings

## Entities

### Memory Fact

Represents a single learned relationship stored in `MEMORY.md`.

| Field | Type | Description |
|---|---|---|
| `text` | string | The natural-language fact, e.g. "Card ending 4605 belongs to UOB Ladies credit card" |
| `embedding` | float32[384] | Embedding vector generated by all-MiniLM-L6-v2 |
| `source_line` | int | Line number in MEMORY.md (for update/delete by exact match) |

**Validation rules:**
- Text must be non-empty and at least 10 characters
- Text must not match any existing fact with cosine similarity ≥ 0.95 (dedup)
- Appended as a new bullet line under `## Facts` section in MEMORY.md

**State transitions:**
```
[does not exist] → learn_fact() → [active in MEMORY.md + index]
[active] → update-fact() → [text replaced, index updated]
[active] → delete-fact() → [removed from file and index]
[active] → periodic rewrite → [text preserved, duplicates removed]
```

### Memory Index

In-memory data structure for fast similarity search. Built from MEMORY.md on startup.

| Field | Type | Description |
|---|---|---|
| `facts` | list[string] | All fact texts, ordered by insertion |
| `embeddings` | ndarray[N, 384] | Pre-computed embedding matrix |
| `initialized` | bool | False until embed() completes first indexing pass |

**Operations:**
- `search(query: str, top_k: int = 5) → list[(text, score)]`
- `add(fact: str) → None` (appends to file + adds to in-memory arrays)
- `remove(match_text: str) → bool` (finds by substring, removes from arrays)
- `rebuild() → None` (re-reads MEMORY.md, re-embeds all facts)
- `deduplicate(threshold: float = 0.95) → int` (removes near-duplicates, returns count removed)

### Notification Cooldown

In-memory suppression map to prevent notification spam.

| Field | Type | Description |
|---|---|---|
| `cooldowns` | dict[str, float] | IMAP msg_id → Unix timestamp of first notification |

**Operations:**
- `should_suppress(msg_id: str) → bool` — true if notified within last 3600s
- `record(msg_id: str) → None` — marks msg_id as notified now
- `clear() → None` — removes all entries (called on update-fact/delete-fact)

**State transitions:**
```
[empty] → notify_user() for ambiguous → [msg_id: now]
[msg_id: T] → should_suppress() within 1h → [suppress]
[msg_id: T] → should_suppress() after 1h → [remove, allow]
[any state] → update-fact() or delete-fact() → [empty]
[any state] → container restart → [empty]
```

## Relationships

```
MEMORY.md (file on disk)
    │
    ▼
MemoryIndex (in-memory, rebuilt on startup)
    │
    ├── search_memory(query) → returns facts to LLM
    ├── learn_fact(fact) → writes to file + updates index
    ├── update-fact(old, new) → rewrites file line + rebuilds index
    └── delete-fact(match) → removes line + rebuilds index

NotificationCooldown (in-memory only)
    │
    ├── notify_user() path → checks before sending
    └── update-fact/delete-fact → clears on correction

Orchestrator
    │
    ├── holds MemoryStore (wraps MemoryIndex + file I/O)
    ├── holds NotificationCooldown
    └── passes tools to LLM via ToolRegistry
```

## Migration from mappings.json

On first start with MEMORY.md (empty or migrated):

1. If `data/mappings.json` exists and `MEMORY.md` does not:
   - Read mappings.json
   - Convert each entry to natural language: `"Toast Box": "Food"` → `"- Toast Box merchant maps to Food payee"`
   - Write MEMORY.md
   - Build index
2. If both exist → MEMORY.md wins (already migrated)
3. If neither exists → create empty MEMORY.md template
